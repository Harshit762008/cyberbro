# cyber bro

Create a simple, beginner-friendly website called CyberSaathi AI.

Design a clean, mobile-friendly cybersecurity dashboard with:

A text box to paste suspicious messages.

An Analyze button.

A section for danger score from 0 to 10.

A section explaining the risk in simple Hindi.

Safety recommendations.

A placeholder for future QR code scanning, link checking, password checking, voice assistance, and emergency support.
